Import from MT5

Full automatic live sync with MT5 is not possible from a simple web app (security + technical limits). Instead, export your deals from MT5 and import them here.

How to export from MT5

  1. In MT5 go to Toolbox → History
  2. Right-click → Report or Save as Report
  3. Choose HTML or open the report and copy the deals table
  4. Or manually note your closed trades and enter them below in simple format
Note: For true automatic tracking you would need a custom MT5 Expert Advisor that writes to a server + a backend. That is more complex and costs money to run. This import method keeps everything private on your phone and is free.
