# Grok Discipline Machine

A focused trading journal built to force discipline for EUR/USD + XAU/USD traders (especially part-time / 9-5).

## Core Philosophy
**Process > Prediction**

Discipline Score is more important than today’s P&L.

## Features
- **Pre-session Commitment** – lock your rules before you trade
- **Daily Session Log** – trades taken, plan followed, emotion, reflection
- **Streaks** – Day streak, Plan streak, Clean days
- **Discipline Score** (0-100) shown permanently in the header
- Individual trade journal with forced honesty when you break rules
- Non-negotiable rules checklist
- MT5 import (paste deals)
- Grok Discipline Bot that will call you out

## Deploy
1. Import this repo on [Vercel](https://vercel.com)
2. Deploy
3. Open in Safari on iPhone → Share → Add to Home Screen

Data stays on your device only.
